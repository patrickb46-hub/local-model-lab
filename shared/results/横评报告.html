本地模型实验室 · 蒸馏 vs 强化学习

同一份 Qwen3.5-2B 复制成两条互不干扰的支线 · 统一任务轴：初中数学小题 + 固定结构化输出格式 · 评测集 52 题（训练前锁定，两条支线均未见过）

一、结论先行

  • 核心命题 · L2 层（teacher 系统性失败、base 尚有机会的题）：teacher 0.0%；A1 · 蒸馏 60 步 16.7% ↑；B · 强化学习 56.2% ↑；C · SFT→RL（同预算） 54.2% ↑。两类方法都越过了 teacher（这一层的区分度不足，需结合差值与显著性判读）。
  • 对照 · L1 层（teacher 会做的题）：teacher 71.7%；A1 · 蒸馏 60 步 53.3%；B · 强化学习 66.7%；C · SFT→RL（同预算） 70.0%。这是蒸馏的主场（它学的就是这些），若此处蒸馏并未领先，说明它的模仿没有真正生效。
  • A1 · 蒸馏 60 步：总体正确率相对 base -2.6pt，格式遵从率 +0.6pt —— 反而更差。多样性 32%，与 teacher 一致性 61%。
  • B · 强化学习：总体正确率相对 base +18.6pt，格式遵从率 -7.7pt —— 有增益。多样性 38%，与 teacher 一致性 46%。
  • C · SFT→RL（同预算）：总体正确率相对 base +20.5pt，格式遵从率 -0.6pt —— 有增益。多样性 22%，与 teacher 一致性 54%。
  • A1 vs B（严格等步数，唯一变量是「模仿 vs 验证器」）：只有 A1 会的 1 题、只有 B 会的 13 题（共 52 题）→ McNemar p=0.0018，显著。
  • B vs teacher：只有 B 会的 14 题、只有 teacher 会的 4 题（共 52 题）→ McNemar p=0.0309，显著。
  • 外部强模型参照（DeepSeek V4 Pro · 云 API）：95.5%，最好的臂 C · SFT→RL（同预算） 51.3% —— 差距明显（差 44.2pt）。顺带一个诚实的观察：云 API 单条 2.0s，本机单条 85.6s —— 在这台没有 GPU 的机器上，本地推理慢一个数量级。
读法：蒸馏支线 A 看"学得像不像 teacher"，强化学习支线 B 看"奖励曲线是否上行"。 两者过程指标本就不同源，只有在下游同一套题上的数字才可直接同框比较。

L3：两者皆全错 → 天花板证据，用来说明「并非所有题都能靠方法解决」。

六、训练过程

loss 是否平稳下降，决定蒸馏有没有真的学到东西； 奖励曲线是否整体上行、格式遵从率是否同时抬升，决定 RL 有没有把行为练出来。 单看奖励上行而多样性掉到 0，通常是"学会了套模板"而非"学会了做题"。

七、thinking 模式的影响（开 vs 关）

⚠ 本表不能横向比较 —— 各角色的 token 预算不同，这是本机算力所迫，不是模型能力差异。
本机角色（base/A/B）的预算是 384 个 token（含思考）。实测它们开思考后， 推理过程会吃光全部预算、正式答案还没开头就被截断 —— 所以「开」这列正确率显示 0%。
Ollama 角色（qwen4b / teacher）同样受 384 约束，只有 33%/0% 走到了正式作答。
云角色（DeepSeek V4 Pro）预算是 1024，思考写完还有余量，所以是 100%。
结论：本表唯一的有效信息是「预算不足时，思考模式会让输出变差」， 而不是「谁更会思考」。要做真正的思考能力对比，得把 think_max_new_tokens 提到 1500 以上 —— 但那意味着本机单题要跑 15 分钟以上， 在本轮不现实。
附带一个有意思的观察：原版 Qwen3.5-2B 的思维链是英文的 （输出形如 Thinking Process: 1. Analyze the Request…），并不是中文。

九、口径说明

格式遵从率：【思路】/【步骤】/【答案】三段齐全且顺序正确，由程序判定。
任务正确率：把【答案】区抽出来与程序生成的 ground truth 比对， 支持分数 / 小数 / 带单位 / 等价形式的归一化比较。
与 teacher 一致性：本模型输出与 9B teacher 输出的文本相似度（空白归一后取比值）。
输出多样性：同一题多次采样之间的平均差异度；越接近 0 说明输出越趋同。
通用能力保持：闲聊 / 常识小测的关键词命中率，用来盯灾难性遗忘。
采样协议：每题用温度 0.7 重复采样 3 次，表中 ± 是逐题均值的标准差。之所以不报 greedy：温度 0 的解码是确定性的， 重复跑结果完全一样，取平均没有任何降误差作用。
多样性直接复用主测的这 3 次采样（同题内两两差异），不需要另跑一轮。
thinking 模式：两种都测。开思考时先剥掉 <think>…</think> 再判分；「开」的条件因输出过长，用小题量探针，故只作趋势参考。
